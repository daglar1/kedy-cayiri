# Kedy Meadow 🐱

A mobile-friendly browser game set in a Minecraft-inspired block world, where colorful cats hop around, follow the player, and respond to affection with pixel hearts.

▶ Play: https://daglar1.github.io/kedy-cayiri/

## Features

- 12 colorful cats with animated movement and following behavior
- Touch controls for mobile devices
- Mouse and keyboard controls for desktop
- Pixel heart effects and audio feedback
- Responsive, full-screen game interface
- No installation required

## Controls

- Tap or click the meadow to move.
- On desktop, use the arrow keys or WASD.
- Press “Sev: kedy” (“Pet the kitty”) to show the cats some love.

## Tech Stack

- HTML5 Canvas for rendering
- CSS3 for responsive styling
- Vanilla JavaScript for game logic and animation
- Web Audio API for sound effects
- GitHub Pages for hosting

## Run Locally

Download the repository and open index.html in a browser.
No dependencies or build tools are required.
